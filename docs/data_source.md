# Fuente de datos de FuelScope

Fuente prevista: [OSINERGMIN, Lista de Precios de combustibles, diaria reconstruida](https://www.datosabiertos.gob.pe/dataset/lista-de-precios-de-combustibles-diaria-reconstruida-partir-de-los-precios-actualizados). El catálogo declara la licencia Open Data Commons Attribution License, codificación UTF-8, delimitador coma y valores ausentes representados como `nan`. La frecuencia de las observaciones es diaria; la frecuencia de publicación indicada por el catálogo es mensual. Estos conceptos no deben confundirse.

Consulta: 18 de octubre de 2026. El recurso CSV listado es `precios_combustibles_anonimizados_20260301_part1.csv` (28,26 MB según el catálogo, con marca de recurso del 11 de marzo de 2026). El diccionario listado es `Diccionario de datos_Precios_Combustible.xlsx`. Estos metadatos no certifican la fecha máxima de observación del archivo.

## Archivos incorporados y actualización

La página rechazó algunas solicitudes automáticas desde este entorno, pero la propietaria descargó y entregó los tres archivos originales desde el navegador. La URL directa de cada recurso respondió después a una descarga normal; los tres SHA-256 coincidieron exactamente con los archivos entregados. Se incorporó un snapshot histórico derivado del CSV y se conservaron los archivos originales en `data/raw`. La [auditoría](data_audit.md) documenta hashes, esquema, cobertura, exclusiones y limitaciones. El diccionario no especifica la unidad física de cada precio y el CSV no incluye territorio. Una [ejecución manual aprobada en GitHub Actions](https://github.com/Kiara1616/FuelScope/actions/runs/39197140063) confirmó el acceso a las tres URLs y que los archivos no habían cambiado. La tarea semanal no descubre nuevas URLs si el portal cambia el nombre del archivo.
